## Zasady oddawania zadań (obowiązują Lab1–Lab3)

1. **Nazwa repozytorium** musi zawierać numer s studenta (lub numery studentów), np. `Lab-1_sXXXXX`.
2. **Każde zadanie** musi mieć **dedykowany branch** z rozwiązaniem (np. `lab1`, `lab2`, `lab3`).
3. **Oddanie zadania** odbywa się wyłącznie przez Microsoft Teams: przesłanie **linku do brancha** z rozwiązaniem (jako **link**, nie jako plik tekstowy).
4. **Każda poprawa** zadania wymaga przesłania **nowego linku** do brancha z poprawionym rozwiązaniem.
5. **Commity** przesłane po ostatecznym terminie oddania będą traktowane jako **oszustwo**.
